Settings — About

A dedicated About entry in Settings for every signed-in person, member or admin. It is the last entry: a row in the phone list, the last row of the settings group in the desktop rail. It opens a small page that says what is running; the loose line at the foot of Settings is gone. A row with ↗ opens GitHub in a new tab (public repository). The dashed outline only marks what is new in this picture.

(a) Release build

The list gains one row; the page names the release, its day and its commit. A member sees Generation, Voices, About; an admin also sees Admin before About (drawn). “What’s new” opens the release’s page on GitHub, which shows the tag’s own message. “Released” is the day in the tag name vYYYY.MM.DD.N.

(b) Build without a release tag

No tag means no release to name: “Version” says “No release”, and “Released” and “What’s new” are not shown (nothing to date, nothing to open). The commit still says what runs. A build with neither tag nor commit (the named constants unreleased and unknown) is only this page with “Commit” reading “Unknown” as plain text, no link; nothing else changes.
