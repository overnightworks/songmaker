Songmaker — component vocabulary

One form per component, for the desktop and the phone alike. The audit found 40 *-btn rules in 29 files, 7 button shapes, 5 tab patterns and 7 overlay implementations. Every specimen below is live CSS on frontend/src/app.css tokens — nothing here is a screenshot. Where the phone differs it stands beside the desktop at 390 px. Round 3 carries the operator's rulings of 20.09.2026: a symbol wherever it is universally understood, a word only for the screen's one primary and inside menus and dialogs; the failure belongs to the control that started it, not to a slot; one take row at both widths; and the ruled colour set — purple acts, red ends — in both themes.

Buttons

A symbol wherever it is universally understood — play, pause, next, close, more, search, add, star, heart, share, copy, trash — a word only for the screen's one primary, and inside menus and dialogs. So: one button — radius 4, Oswald uppercase — in four roles: primary (a word, filled), icon-only (32/44, a symbol), destructive (DELETE, red, only in a confirm dialog) and secondary (outline with a word, only inside a dialog — CANCEL) — plus one reserved shape, the play/pause circle. Busy, disabled and failed are states of the primary, not roles. Every icon carries an accessible name and, on a pointer, a tooltip with the same words. A pill, a chip, a tab and a link are not buttons.

Tabs, segments, radio rows

Three ways to choose, one each: a tab strip (12 px uppercase, 2 px accent underline, 44 px tall at both widths, scrolling sideways) switches views; a segmented control of the same metrics picks a short value that fits on one line; a radio row list picks a value that needs its own name — one row, one dot, its explanation behind ⓘ. A native <select> replaces none of them, at any width. The strip's 44 is the one height that is not a face plus the grid (§10): a tab is a place to stand, not a face to press, and it stays one height on a mouse and a finger.

Two overlays, no third: a popover for up to eight actions — sentence case, one icon each, the destructive row last and red, clamped inside the viewport at every width — and a modal only to confirm or to publish. Editing content is never a modal; it happens inline, in a collapsible card. A setting that needs confirming before it takes effect stays a dialog — that is why ShareDialog remains one: it publishes.

Colour — meanings ruled

Red meant five things (brand, active tab, selected segment, focus ring, delete) and purple three (playing, pick, me). What is ruled is the meaning, not the hex (operator ruling 20.09.2026): purple is where you act and where you are, red means only a person can end this — a failure and a delete. The values are tokens in app.css, and the operator changes them at will; every component reads the token and never a literal. A state colour is the product's own token and is never the action colour — but “playing” is presence, not state: it says where you are, so it wears the action colour like the active tab does.
